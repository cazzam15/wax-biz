    Why keep a batch log

    If a customer reports a problem, such as a reaction, a weak scent or oil on the surface, a batch code on the label tells you exactly which wax, oil and load went into that melt, and which supplier's Safety Data Sheet applies. Without one, you are guessing which batch it came from.

    A log also makes your good results repeatable. When a scent throws well, you can see the load, temperatures and cure time that produced it, and use "Make again" to start the next batch with the same recipe. When something goes wrong, the notes help you spot the pattern, whether it's frosting at a certain pour temperature or sinkholes in one mould.

    What to record

    • Batch code and date: the code goes on every label from the batch.
    • Wax and fragrance oil: include the brand and supplier, as the same scent name differs between suppliers.
    • Fragrance load and temperatures: the main causes of differences between batches.
    • Units made and cure time: so you know what's ready to sell and when.
    • Throw ratings and notes: fill these in after testing, so the next batch is better.

    Frequently asked questions

    Where is my batch log saved?

    In your browser on this device only. Nothing is sent to The Wax Biz or anyone else. That also means clearing your browser data, or switching to another phone or computer, will not bring it with you, so download a backup regularly and restore it on the new device.

    What should a wax melt batch code look like?

    Anything short and unique that you can print on the label. This log suggests one based on the date, such as B261007-1 for the first batch made on 7 October 2026. Put the same code on every label from that batch so you can trace any problem back to it.

    How long should wax melts cure?

    Most makers cure soy and coconut blends for at least 48 hours and often one to two weeks for the best scent throw. Paraffin needs less. The log uses 7 days by default and shows when each batch is ready, but test your own wax and oils.
